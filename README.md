# SP-Friend

해당 프로젝트는 프록시용 친구 프로젝트 입니다

해당 플러그인을 사용하기 위해선 SP-Framework가 필요합니다

## 플러그인 버전

- 플러그인 : spigot 1.21.11 (Java 21)
  - base 버전 사용

## config

bukkit/plugins/SP-Friend/config.yml

```
proxy:
  # SP-Framework WebSocket 프록시를 통한 서버 간 접속 상태/알림 동기화
  enabled: true
```
